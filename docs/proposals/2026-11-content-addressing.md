# 提案：内容寻址与有界上下文读取（向量世界的 grep 语义）

> 状态：proposed（2026-11-06）。来源：用户设计拔高（2026-11-06）——「不只是 PDF 页数，而是内容
> 精确定位的统一机制：agent grep 定位到行、读上下文只读相邻几行而非全文件；大 PDF/EPUB 全文可
> 能超过 LLM 上下文长度」。吸收 backlog F6（chunk 读）/F8（页归属）并统一之。
> 对应 ADR：`docs/adr/0005-content-addressing-bounded-reads.md`；
> 设计：`docs/design/2026-11-content-addressing.md`。

## 1. 问题

检索命中之后，agent 的标准工作回路是「定位 → 读局部上下文」，而当前工具面只有两个极端：

- **命中不可寻址**：hit 携带 chunk key（ opaque 串）与源文件名，但无文档内坐标——不知道在第几
  页/第几行/第几节，无法向用户引用、无法按范围收窄检索；
- **读取只有全文件**：`vf cat` / GetSourceData 是全文透传。grep 世界的基本动作——「命中第 412 行，
  读 405–420 行」——没有对应物。对 2.7MB 的 PDF、21MB 的教材、乃至 EPUB 容器，**全文读取在
  LLM 上下文预算下根本不可行**，agent 被迫自行下载 + 自建提取管线（dogfooding 会话实证）。

病根：chunk 序号（`{hash}-text-{i}`）事实上就是「向量世界的行号」，但它从未被**声明为契约**；
文档原生坐标（页/行/节）在提取层被丢弃（§5.10.2 单 Part 压平，与结构标签提案同一病根）；
读取原语缺席。

## 2. 目标 / 非目标

**目标**
1. **坐标键集**：chunk 携带文档原生坐标（pdf → 页、txt/md → 行、容器 → 子文档序号），全部
   filterable 数值，支持 `$gte/$lte` 范围收窄（「只搜第 10–50 页」）；
2. **chunk 序号契约化**：`{hash}-{modality}-{i}` 声明为**有序、可枚举、可寻址**的文档地址空间
   （i 随文档序单调），邻域读取 = `i±N`；
3. **有界读取原语**：`vf chunk show --around N --chars B`——grep -C 语义，输出按预算截断并
   标记，永不超 LLM 上下文；
4. **三源坐标**：提取层（页偏移表）、chunker（行计数，免费）、容器编排（子文档序号）——同一
   键集，三个来源，无第四处猜测。

**非目标**
- 不做服务端原文窗口读取（`vf read --pages` 类，pdfium 定页重提取）——chunk 邻域已覆盖 agent
  回路（读到的就是索引所见视图）；原文窗口需求出现时另行提案（v2 演进钩子留于设计 §6）；
- 不做印刷页码 label（pdfium `FPDF_GetPageLabel`）——1-based 物理页索引先行，label 后置；
- 不做字符级偏移寻址——chunk 粒度即坐标粒度，更细归 v2；
- 不新增 `/x-vf/` 操作——坐标进 metadata（既有 Search/GetVectors 面），邻域读取是客户端
  拼装（既有 GetVectors）。

## 3. 方案选项

| 选项 | 评估 |
|---|---|
| **A. 坐标键集 + chunk 序号契约 + 客户端邻域读**（推荐） | 零新 API 面、零服务端改动（读取侧）；坐标三源各有天然落点（结构标签的 Part 手术顺车）；数值 filterable 直接获得范围收窄 |
| B. 服务端原文窗口 op（GetSourceContext） | 能读"raw 视图"，但新增第 9 个超集 op + 服务端定页重提取管线；chunk 邻域先覆盖回路，需求实证再上 |
| C. 仅页码键（不契约化序号） | 只解决 pdf 归属，txt/epub 无坐标；chunk 序号仍是实现细节，`vf chunk show` 无契约根基 |
| D. 依赖 M3 T3 页图像 | 页归属被绑到图像模态（T3 本务是渲染嵌入），文本块坐标被无关里程碑阻塞 |

## 4. 关键取舍

1. **坐标单位按格式最小化**：pdf → `page`（无行概念）；txt/md → `line`；容器子文档 →
   `section`。**不做笛卡尔积**（pdf 不打行、txt 不打页）——键只在单位存在时写入，`$exists`
   语义自然区分；
2. **物理页索引而非印刷页码**：无歧义、可过滤；雷达类文档前置目录致 label 偏移，label 作
   后置增强；
3. **邻域读取读"索引所见视图"**（chunk 文本，含家具剔除/标签后的管线视图）而非原文——
   agent 读到的与检索命中的是同一真相，无需二次对齐；
4. **读取预算硬界**：`--chars B` 截断 + `truncated` 标记 + 续窗指引（下一 chunk key）——
   「永不超上下文」是构造属性而非约定。

## 5. 依赖与风险

- 依赖：Part 手术（与结构标签设计共享——页偏移表与 labels 同一 additive 字段族）；chunker
  行计数（token_window 全文在手，免费）；容器编排 stamp section（M3 T7 epub 落地时激活，
  键集先行占位）；`x-vf-chunk-kind` 同族的 metadata 键集增补（§5.10.1）。
- 风险：chunk 序号契约化后 key 结构不可随意演化（ADR-0004 已声明同款约束）；跨页 chunk 的
  页区间如实重叠（如实反映不去重）；存量索引 reindex 后获得坐标（与结构标签同批迁移）。
