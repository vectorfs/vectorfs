# 提案：叙事语料召回缺口三机制（R7 查询分析器同源 / R8 结构轴查询面 / R9 叙事金标集）

> 状态：**proposed**（2026-11-11）。
> 来源：dogfooding 会话 2026-11-11——《诡秘之主（含番外）》epub（15,428 chunk）上的 8 轮检索，
> 病灶 FM1–FM5 全程可复现（命令存档于会话）；机制谱系为
> `research/2026-11-recall-quality-optimization.md` R1–R6 路线图的延长线（编号续 R7–R9）。
> 前置用户裁决（2026-11-11）：**真 BUG 直接修，机制缺口走路线图**——本提案只含后者；
> 真 BUG 清单见 §5（实施期随任务直接修，不占裁决位）。

## 1. 问题

R1–R4 已按雷达语料的病根落地，但在叙事类语料（长篇小说 epub、回忆录型长文）上实测出
**三类机制性失效**——其中两类是既有机制的结构盲区，一类是新失效维度：

- **FM1（R1 结构盲区）锚词门控对纯 CJK 查询零锚**：锚词候选要求含 ASCII 字母
  （`lexical.rs:231`），纯中文词永远进不了候选——含引号短语的逃生口同样被拦；模块文档自述
  "pure-CJK queries analyze to zero anchors"（`lexical.rs:22-24`）。会话 8 条中文查询全部
  零锚，门控全程空转。病根：v1 用「ASCII 标识符形状」作 round-trip 稳定性代理，等于在查询侧
  造了第二个分词器，与索引 analyzer 平行漂移。
- **FM2（新失效维度）事件定位查询「复述压倒场景」**：「第一次升上灰雾」「服下占卜家魔药」
  这类**事件定位**查询，top-k 全是回溯/复述段（事件发生一次、被复述数十次，复述段在查询词上
  语义密度更高），嵌入与 cross-encoder 双双受骗（九实验 F 的同构病）。雷达语料没有「复述」
  结构，金标对此维度失明。
- **FM3（半成品面）时序/弧段问题无原生操作**：「先 A 还是先 B」「第一卷内的 X」需要围栏+
  位置比较。T13 已让坐标键 filterable（实测 `{"x-vf-section":{"$lte":20}}` 生效），但位置
  不是一等检索轴：无范围语法糖、无 TOC 节点解析、无位置序——会话最终 epub+grep 逃生，
  说明真实工作流有个 vf 不覆盖的洞。同根发现：**R2 的 CCH 对容器源退化**——容器子文档无
  TOC 页概念，`Part.sections` 为空、前缀退化为常量文件名 stem（`ChunkCtx` 仅此一字段，
  `windowing.rs:114-132`），整部小说每个 chunk 的嵌入前缀相同，R2 的章节语境红利为零。

伴随（真 BUG 级，非机制）：T15.4 的 skill 文档义务未执行——vf-search skill 仍称
"only `x-vf-src-uri` is filterable"，且 `--mode/--rerank/--rerank-depth/--per-source/--kind/
--source` 七个已交付旗标无一记载；`anchors` 观测成员（`ops_xvf.rs` 响应契约）CLI `--json`
未透传。

## 2. 目标 / 非目标

**目标**
1. **R7 查询分析器同源**：锚词候选出自与索引内核同一分词策略——CJK 查询产出真实锚词；
   df 门限从雷达标定魔数（`ANCHOR_DF_CEILING = 16`）升级为查询内探针分布自校准；
2. **R8 结构轴查询面**：section 范围围栏、TOC 节点定位、位置序（「最早命中」）成为 /x-vf 与
   CLI 的一等原语；同一手术补全 R2 的 CCH 容器形态（章题进嵌入前缀）；
3. **R9 叙事金标集**：全合成叙事语料生成器（场景 vs 复述维度、跨源诱饵），R7/R8 的疗效以它
   过门（D-4「零版权材料」纪律）。

**非目标**
- 不做复述段检测器（零 LLM 纪律下无从检测；R8 的立场是**绕过**——「验证某事件是否首次出现」
  变成一条位置序查询，不正面治 FM2 的排序病）；
- 协议面（QueryVectors）零变化，新面全部落 /x-vf 与 CLI（ADR 0002/0004 先例）；
- 研究文档「明确不做」清单维持：不做查询路由器 / MMR / HyDE / LLM 上下文化；
- R5 模型轴（Qwen3-0.6B）不动排期——R9 金标为它新增叙事场景列，裁决仍按原计划。

| | B. 放宽 ASCII 检查让 CJK 串进锚候选 | 否——形状启发式续命，第二分词器继续漂移，打补丁 |
| | C. 双列双 tokenizer 三路 RRF | 维持提案 0002 的「进阶留门」定位，不在本提案动 |

## 4. 关键取舍

1. **稳定性由构造保证**：R7 的锚词与索引词出自同一上游（crate 版本线对齐 + 差分断言），
   取代 v1 的形状启发式；断言扩展挂 T9「分词差分断言」既有先例；
2. **章题溯源退级链**：epub 优先解析 NCX/nav 目录标签，退级到子文档首个 heading 行，再退级
   到子文档名——提取层一次性手术，**CCH（索引面）与 `x-vf-section-title`（查询面）共用**；
3. **迁移语义**：`x-vf-section-title` stamp 与容器 CCH 前缀都是指纹变更 ⇒ reindex
   （T13 坐标键同批先例措辞）；docs 桶唯一受影响源是 15,428 chunk 的 epub，代价如实入
   迁移说明；
4. **orderBy 是扫描序视图不是排序语义**：终局命中集内按 (section, line) 排序、分数保留展示、
   与 mode 正交；与 rerank/kind 排除同类——ranking policy 不入指纹（T11/T12 先例）。

## 5. 依赖与风险

- **真 BUG 清单（实施期直接修）**：①vf-search skill 过滤句与旗标记载义务（T15.4 遗留）；
  ②`anchors` 成员 CLI `--json` 透传核验（缺则补线）；
- 依赖：`icu_segmenter` 显式进 server 依赖树（与 lancedb 锁定版本线对齐——依赖对齐是差分
  断言的前提）；`ChildDoc` 增 title 字段（extract 手术，additive）；
- 风险：①icu 版本漂移致查询侧与 lance 内部分词漂移——差分断言拦截；②`--at` 的客户端枚举
  成本——T14 early-exit 前缀枚举有界（O(源 chunk 数)，15k 级实测可忽略）；③orderBy 被期望成
  语义排序——文档措辞钉死「扫描序视图」；④epub 章题退级链对无 nav 无 heading 的极端 epub
  退化为子文档名——行为如实文档化（有界退化，非错误）。
