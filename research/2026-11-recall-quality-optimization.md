> 来源：验收会话的九组对照实验（本地实测，命令可复现）+ 两路外部 SOTA 调研（一手来源核验：

## 1. 实测病灶解剖（九实验全表）

| # | 实验 | 结果 | 结论 |
|---|---|---|---|
| A | 语义 + rerank@5 | ✗ 目录扩散块霸榜 | rerank 救不回不在候选集的块 |
| B | hybrid + rerank | ✗ FAQ/方法论块夺魁 | cross-encoder 也被表面主题匹配骗 |
| C | **剥离结构词**（"vibe coding 技术有哪些变化"） | ✓ 语义 rank-1/2 正解 | 病因 = 查询中的语料结构词 |
| D | 源+页过滤下正解排序 | ✓ 局部全对 | 块质量无恙，纯全局排序问题 |
| E | rerank 延迟 | 148ms/pair（k10=1.8s，CPU） | 可用但非当前瓶颈 |
| F | **深候选 rerank@50** | ✗ 正解居 41 | **reranker 本身被方法论段落骗** |
| G | keyword 单路 | ✗ 目录块 18.8 分 | BM25 短文档长度归一化放大关键词密集目录块 |
| H | hybrid 单路@5 | ✗ 同上 | 三路浅层全灭 |
| I | **hybrid@50** | ✗ 正解居 27，top-10 全 p1-5 扩散块 | **业界收敛栈对起源查询整体无效** |

**病根三要素**：
1. **查询未分解**——`vibe coding`（df≈2，判别性锚词）与`技术雷达/技术/变化`（df 数百，语料结构词）
   被三路当整体处理，锚词判别力被洪泛稀释；
2. **索引侧语境缺失**——目录块与正文块在嵌入空间共享"结构词优势"（都含 技术雷达/平台/工具），
   嵌入器与 cross-encoder 都无章节语境可分；
3. **跨源洪泛**——5 期雷达各贡献 2-3 个目录扩散块（body kind，T12 判定漏网的边界窗），跨源
   分布使 per-source 配额失效（配额治同源挤占，不治此症）。

## 2. 外部证据校准（两路调研要点）

- **Anthropic 35/49/67% 口径**：top-20 检索失败率降幅；67% 是「嵌入+BM25+rerank 全栈」。
  vectorfs 已有后两级（hybrid+gte reranker）——实测 hybrid 对词锚查询 rank-1 救回与此互证：
  **既有栈是被背书资产，问题是它对"结构词洪泛查询"无解**（实验 I）。
- **业界收敛形态**（Bedrock 托管 KB 恒 hybrid+rerank 默认开、OpenAI file search 恒双路）：
  托管级建立在 GPU/弹性上；CPU 自托管档一手数据（本仓 148ms/pair + Qdrant bge 档 16-45
  docs/s）否决「rerank 无条件默认开」。**规则路由器无大厂先例**——业界用恒 hybrid 消灭路由
  问题而非做聪明路由；但实验 I 证明恒 hybrid 也不够，vectorfs 语料病灶超出业界收敛栈覆盖。
- **rerank/返回深度解耦**是通行惯例（Anthropic 150→20、Vespa 100、ES rank_window_size）；
  vectorfs 现状 rerank 候选=截断 topK（绑死），且两臂无 over-fetch——红利通道关着。
- **flooding 方子是分组配额不是 MMR**（Qdrant 官方）；per-source 分组键已在 attribution map 里。
- **上下文化**：LLM 版（-35%）违反零 LLM 纪律；**结构化 heading-path 前缀（CCH）零 LLM 零依赖**，
  是抽取式替代；late chunking 三重否决（CLS pooling 不兼容 + jina CC-BY-NC + 无中文证据）。
- **模型轴**：Qwen3-Embedding-0.6B（C-MTEB 66.33，Apache，MRL 768，32K）是现役 gte 的继任
  候选；ONNX 仅社区导出（供应链校验成本）；query 前缀是模型族属性（进内置表非用户轴）。

## 3. 机制路线图（按「对实测病灶的疗效证据 / 成本 / 机制契合」排序）

### R1 锚词门控词法（minShouldMatch + df 统计）——唯一直接击穿起源查询的机制

- **机制**：查询面拿 FTS 索引的词频统计把查询分解为 {锚词（df < 阈值）/ 语境词}；词法路由加
  **minShouldMatch = 锚词数**（附录 C Fusion 蓝本 T9 保留的 `$textMatch(operator/minShouldMatch)`
  正是此参数）——不含锚词的块（全部目录扩散块）直接出局词法路；正解块词法 rank-1，RRF 数学上
  必然抬升（1/(60+1) + 1/(60+13) ≈ 0.030 > 目录块纯语义 0.016）。
- **证据**：实验 G/H/I（结构词洪泛下三路全灭）+ C（锚词即全部判别力）+ F1 闭环史（zxqwibble
  semantic 不中/keyword top-1）+ Anthropic TS-999 论证（精确标识符是 BM25 独占域）。
- **诚实声明**：业界无「df 阈值选锚词」的产品级先例（大厂收敛于恒 hybrid）；本机制是
  vectorfs 原生提案，内部实验证据强于外部先例。df 统计的获取路径（Lance FTS 是否暴露词频表，
  或查询期探针）需实施前 spike。
- **成本**：查询面纯策略（不入指纹先例）；零新依赖；fts=off 时优雅降级纯语义。
- **风险**：锚词误判（用户真正想搜高频词）——minShouldMatch 只收紧词法路，语义路不受影响，
  误判代价 = 丢失词法增强而非丢失结果。

### R2 结构化 heading-path 前缀（CCH）——索引侧语境，三路（嵌入/BM25/reranker）普惠

- **机制**：extract 已有结构信号（structure.rs 的标题层级 + TOC 判定），把「文档标题 > 章节
  路径」≤80 token 前缀进 chunk 的**嵌入输入**（正文返回不变）；`chunk` 轴配置
  `context_header = "heading-path" | "none"`。
- **对病灶的机制**：目录块前缀 =「…> 目录」，正解块前缀 =「第32期 > 技术 > 自满于 AI 生成的
  代码」——嵌入器与 cross-encoder（重排输入同带前缀）都获得判别语境；实验 F 的 reranker
  受骗面直接收窄。
- **成本**：全量重嵌（指纹自然翻转）；每 chunk 推理 +几十 token。LLM 版参照 -35%（抽取式
  取方向不取数值）。
- **与 R1 正交**：R1 治查询侧，R2 治索引侧；叠加后起源查询两条病根同时拔除。

### R3 恒 hybrid 推荐位形 + 候选深度解耦——业界收敛面，低成本先落

- `text-rag` preset 缺省 `fts = true` + 文档把 hybrid 标为推荐档（零代码或近零）；
- rerank 候选深度独立请求位（缺省 =topK 零行为变化；`depth 20` ≈ 3s CPU 诚实预算入文档）；
  融合 over-fetch 2×topK 起步（毫秒级）——Qdrant 证据：深度红利 +0.10~0.28 nDCG 上限，
  但要后段用得上（本仓 rerank 深度绑死 = 通道关着）。
- 注意：本组对起源查询无效（实验 I/F），价值在普遍召回上限与词锚查询之外的常规查询。

### R4 per-source 配额（grouping）——治同源挤占（真实但不同的病）

- 诚实校准：调研路 P1 称"直击实测痛点"**不成立于起源查询**——目录扩散块跨 5 源分布，配额
  无效；配额治的是"单文档多块挤占 top-k"（教科书 794 块的场景真实存在）。默认每源 2-3，
  attribution map 已有分组键，微秒级。
- MMR 不做（Qdrant 方子排序：grouping 先于 MMR；且与"命中回源"语义相悖）。

### R5 模型轴：Qwen3-Embedding-0.6B 进内置表作可切换候选

- 中期项：全量重嵌不可避免 + 社区 ONNX 校验成本 + decoder-only 推理慢；收益 C-MTEB 66.33
  vs 现役（2024 mGTE）。与 R2 同批重嵌可摊薄迁移成本。bge-m3 维持"一行可换"备选（sparse
  通道与 Lance FTS 重叠，性价比低）。

### R6 金标评测集——R3 深度调优 / weighted RRF / 锚词阈值的数据地基

- golden_corpus + 雷达语料的已知正解（本会话九实验即雏形）固化为可重跑评测集；Qdrant 决策表：
  无评测集 → 手调权重不太可能稳定胜过默认（weighted RRF 与锚词 df 阈值的调优都以此为前提）。

### 明确不做

LLM 上下文化与 HyDE（零 LLM 纪律）；late chunking（三重否决）；规则路由器（无先例 + 恒 hybrid
更被验证——R1 是词法路约束不是路由，不冲突）；MMR（R4 之后无位）；「对 TOC 检索期 soft boost」
（业界无先例，T12 排除 + R1 门控 + R2 语境已三层覆盖）。

## 4. 建议落地序（裁决请求）

| 序 | 项 | 成本 | 对起源查询 |
|---|---|---|---|
| 1 | R3（hybrid 推荐位 + 深度解耦） | 近零 | 无效但普惠 |
| 2 | R1（锚词门控） | 查询面小改 + df spike | **有效**（数学可证） |
| 3 | R2（CCH 前缀） | 全量重嵌 | **有效**（语境判别） |
| 4 | R4（配额） | 查询面小改 | 无效（治另病） |
| 5 | R6（评测集）→ R5（模型轴）| 中期 | 间接 |

R1+R2 组合后起源查询预期：词法路锚词门控出局全部扩散块 → 正解词法 rank-1 → RRF 抬头 →
CCH 语境使 reranker 不再受骗 → 深度解耦给 rerank 足够候选。四层齐下，该查询形态从"三路全灭"
到"机制可解"。
